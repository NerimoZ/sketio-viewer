# Open a document

Drag a Markdown file into this window, or press **Ctrl+O** to browse.

## Find your place

Press **Ctrl+F** to find text on the page. Links to other Markdown files open here. Press **Alt+←** to go back.

Switch themes whenever you like. Sketio remembers your choice.

## Shortcuts

| Shortcut | Action |
| --- | --- |
| **Ctrl+O** | Open Markdown |
| **Ctrl+F** | Find in the document |
| **Ctrl+R** | Reload the file |
| **Alt+←** | Previous document |
| **Ctrl+Shift+L** | Switch theme |
